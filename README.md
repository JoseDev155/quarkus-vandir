# VANDIR

Sistema de inventario para tiendita, de la asignatura Sistemas Informáticos "A".

## Tecnologías Utilizadas

* **IA**: Gemini CLI (Suscripción Pro de Google)
* **Backend**: Quarkus (Java)
* **Base de Datos**: MySQL
* **Frontend**: Vue.js
* **Autenticación**: JWT (JSON Web Token)
